# Dependency-Based Task Organiser
In this application, some task B can come after some task A: in doing so, only task A is available for completion, and only when it is completed does task B becomes available.

Any tasks can be connected to any other tasks to enforce order. This appears in the form of a visual graph display. 

## Installation
Clone the repository. Using vite:

```
cd ui
vite build
```
